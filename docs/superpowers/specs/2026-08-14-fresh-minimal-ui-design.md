# 橙子管理系统 · 清新极简 UI 设计方案

- 日期：2026-08-14
- 项目：orange-admin（RuoYi-Vue3 + Element Plus 2.13 + Vite 6）
- 范围：全系统统一简约风
- 方向：清新极简（浅色为主、低饱和点缀、大量留白）

## 1. 设计目标

1. 全系统视觉统一：登录 / 注册 / 首页 / 管理列表页共享同一套设计令牌。
2. 清新极简：去除高饱和渐变与彩虹色图标，回归留白、层次与低饱和点缀。
3. 低侵入：业务列表页（system / monitor / tool 各页面）不逐个改动，通过全局样式覆盖统一观感。
4. 保留既有能力：暗黑模式、动态主题色、侧边栏主题切换、布局设置抽屉全部保留可用。

## 4. 各区域改造方案

### 4.1 登录页 / 注册页（`login.vue` / `register.vue`）

- 由"居中卡片 + 大背景图"改为左右分栏：左侧品牌区（浅蓝渐变底 + 系统名 + slogan + 极简几何装饰），右侧白底表单区。
- 表单输入框圆角描边样式，主色全宽按钮，验证码图片去硬边框。
- 标题升至 20px，留白翻倍。
- 暗黑模式：品牌区加深，表单区用 `--el-bg-color-overlay`。

### 4.2 首页（`index.vue`）

- 去掉三色渐变欢迎横幅与 8 色渐变图标卡片。
- 改为：白底欢迎条（问候语 + 系统名 + 简短说明，纯静态文案）+ 功能入口卡片（线性图标 + 中性色，激活主色点缀）+ 精简系统介绍。
- 图标统一使用线性风格，去掉每个模块不同的渐变色背景。
- 不引入后端数据接口，避免超出 UI 改造范围。

### 4.3 整体布局

- 侧边栏默认切换为浅色主题（白底、文字 `#4E5969`、激活项主色文字 + `#DBEAFE` 浅底）。
- 导航栏白底、去多余分割线，高度 56px。
- 标签栏改圆角卡片样式，激活态主色边框 + 浅色底。
- 页面背景统一 `#F7F8FA`。

### 4.4 管理列表页（全局样式覆盖，不改业务代码）

- 搜索栏白底圆角卡片化。
- 表格去斑马纹，表头浅灰底 `#F7F8FA`，行悬停 `#F2F3F5`。
- 操作列实心按钮改文字按钮（主色文字，删除用 danger 色）。
- 弹窗圆角 12px。

## 5. 实现策略（方案 B：变量 + 关键页重写）

| 层级 | 做法 |
|------|------|
| 全局令牌 | 新增 `src/styles/fresh-theme.scss`，覆盖 Element Plus CSS 变量与组件样式 |
| 主题色 | `src/settings.js` 默认主题色改 `#3B82F6`；`src/store/modules/settings.js` 默认值同步 |
| 侧边栏 | `src/settings.js` 默认 `sideTheme: 'theme-light'`；`variables.module.scss` 浅色变量微调 |
| 关键页重写 | `login.vue`、`register.vue`、`index.vue` |
| 布局微调 | `Navbar.vue` 高度与分割线、`TagsView` 激活态样式（主要靠全局覆盖） |

## 6. 验收标准

1. 登录、注册、首页、至少一个管理列表页（用户管理）视觉统一为清新极简风格。
2. 暗黑模式切换后各页面仍可读，无刺眼高饱和色。
3. 动态主题色（布局设置抽屉）仍可切换，主色联动生效。
4. 侧边栏浅色/深色切换仍可用。
5. 业务功能不受影响：登录、注册、验证码、增删改查、上传均正常。
6. 构建无报错：`npm run build` 通过。
